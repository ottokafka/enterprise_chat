Normal Chat Completion

Generate conversational responses from the standard text model using a messages array.

curl http://localhost:4445/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d '{
    "model": "Qwen3.5-35B-A3B-GGUF",
    "messages": [
      { "role": "system", "content": "You are a helpful assistant." },
      { "role": "user", "content": "Hello!" }
    ],
    "temperature": 0.7
  }'
Response
{
  "id": "chatcmpl-123",
  "choices": [{
    "index": 0,
    "message": { "role": "assistant", "content": "Hello! How can I assist you?" },
    "finish_reason": "stop"
  }]
}

Chat completions with File Uploads

Upload files (PDF, XLSX, Images, etc.) alongside your messages using multipart/form-data.

curl http://localhost:4445/v1/chat/completions \
  -H "Authorization: Bearer API_KEY" \
  -F "model=qwen3.5" \
  -F 'messages=[{"role": "user", "content": "Analyze these files."}]' \
  -F "file=@/path/to/report.pdf" \
  -F "file=@/path/to/data.xlsx"
Response
{
  "id": "chatcmpl-456",
  "choices": [{
    "index": 0,
    "message": { "role": "assistant", "content": "I've analyzed the PDF report and the XLSX data. Here's a summary..." },
    "finish_reason": "stop"
  }]
}

Tool Calling

Define functions that the model can choose to call, enabling it to interact with external tools and APIs.

curl http://localhost:4445/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d '{
    "model": "qwen3.5",
    "messages": [
      { "role": "user", "content": "What is the weather in Tokyo?" }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "get_weather",
          "description": "Get the current weather in a given location",
          "parameters": {
            "type": "object",
            "properties": {
              "location": { "type": "string", "description": "The city and state, e.g. San Francisco, CA" },
              "unit": { "type": "string", "enum": ["celsius", "fahrenheit"] }
            },
            "required": ["location"]
          }
        }
      }
    ],
    "tool_choice": "auto"
  }'
Response
{
  "id": "chatcmpl-tool-123",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": null,
      "tool_calls": [{
        "id": "call_abc123",
        "type": "function",
        "function": {
          "name": "get_weather",
          "arguments": "{\"location\": \"Tokyo\", \"unit\": \"celsius\"}"
        }
      }]
    },
    "finish_reason": "tool_calls"
  }]
}

Web Search

Enable the model to search the internet for real-time information. You can use a simplified toggle or the native tool calling schema.

Option 1: Simplified Toggle

Add "web_search": true to your request. The server will automatically choose the best search queries and ground the answer with sources.

curl http://localhost:4445/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d '{
    "model": "qwen3.5",
    "messages": [
      { "role": "user", "content": "What is the current stock price of NVIDIA?" }
    ],
    "web_search": true
  }'
Option 2: Native Tool Calling

Manually define the web_search tool to give the model fine-grained control over when to use it.

curl http://localhost:4445/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d '{
    "model": "qwen3.5",
    "messages": [
      { "role": "user", "content": "Check the news for today." }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "web_search",
          "description": "Search the internet for real-time information",
          "parameters": {
            "type": "object",
            "properties": {
              "queries": {
                "type": "array",
                "items": { "type": "string" }
              }
            },
            "required": ["queries"]
          }
        }
      }
    ]
  }'
Response
{
  "id": "chatcmpl-search-123",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": "As of today, NVIDIA (NVDA) is trading at... [1]\n\nSources:\n[1] [NVIDIA Stock Quote](https://quote.com/...)"
    },
    "finish_reason": "stop"
  }]
}

Anthropic Claude Compatibility

Full compatibility with Anthropic SDKs and libraries using the /v1/messages endpoint. Supports both base64 and remote URL vision blocks.

curl http://localhost:4445/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-3-opus-20240229",
    "max_tokens": 1024,
    "system": "You are a helpful assistant.",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "image",
            "source": {
              "type": "url",
              "url": "https://upload.wikimedia.org/wikipedia/commons/a/a7/Camponotus_flavomarginatus_ant.jpg"
            }
          },
          {
            "type": "text",
            "text": "What is in this image?"
          }
        ]
      }
    ]
  }'
Response
{
  "id": "msg_01XFDUDYJgAACzvnptvVoYEL",
  "type": "message",
  "role": "assistant",
  "content": [
    {
      "type": "text",
      "text": "This image shows an ant close-up..."
    }
  ],
  "model": "claude-3-opus-20240229",
  "stop_reason": "end_turn",
  "usage": {
    "input_tokens": 1551,
    "output_tokens": 71
  }
}

Document Reranking

Re-score and rank a list of documents based on their relevance to a search query.

curl -X POST http://localhost:4445/v1/rerank \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d '{
    "model": "Qwen3-Reranker-8B",
    "query": "What is machine learning?",
    "documents": [
      "Machine learning is a subset of artificial intelligence that enables systems to learn from data.",
      "Deep learning uses neural networks with multiple layers to process information.",
      "Artificial intelligence encompasses both machine learning and deep learning."
    ],
    "top_n": 2
  }'
Response
{
  "model": "Qwen3-Reranker-8B",
  "object": "list",
  "usage": { "prompt_tokens": 266, "total_tokens": 266 },
  "results": [
    { "index": 0, "relevance_score": 0.9836259484291077 },
    { "index": 2, "relevance_score": 0.10805725306272507 }
  ]
}

RAG Pipeline (Retrieve → Augment → Generate)

Search through your indexed documents and generate an answer based on the retrieved context.

curl -X POST http://localhost:4445/v1/rag \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer API_KEY" \
  -d '{
    "query": "What are our security protocols?",
    "document_names": ["npro_public_knowledge.md"],
    "top_n": 5,
    "stream": false
  }'
Response
{
  "query": "What are our security protocols?",
  "answer": "Based on the security manual, our protocols include...",
  "citations": [
    { "id": "chunk_1", "text": "...", "metadata": { "source": "npro_public_knowledge.md", "page": 1 } }
  ],
  "meta": {
    "retrieved": 5,
    "dense_count": 20,
    "sparse_count": 20,
    "reranked": true
  }
}
